# رَصيدي

واجهة عربية RTL متجاوبة لإدارة المال الشخصي، بهوية مستقلة وبيانات تجريبية محلية.

## التشغيل

افتح `index.html` مباشرة للمعاينة الأساسية. يتطلب التثبيت والعمل دون اتصال تقديم الملفات عبر خادم HTTPS أو localhost حتى يعمل Service Worker.

## الوظائف الموجودة

- لوحة شهرية للرصيد والدخل والمصروف والميزانية، ورسم لحركة الأموال.
- تسجيل الدخل والمصروف، التصنيفات، الحسابات، عملات IQD وUSD وEUR، والعمليات المتكررة.
- البحث والتصفية عبر المعاملات، وتصدير CSV قابل للفتح في Excel.
- طباعة التحليل أو المعاملات إلى PDF باستخدام خيار الطباعة في المتصفح.
- ميزانيات لكل تصنيف، أهداف ادخار مع إضافة مساهمات، وسجل ديون.
- تسديد الديون يدوي فقط، مع تنبيه داخل التطبيق عند حلول الموعد أو تجاوزه.
- مظهر داكن افتراضي، وملف شخصي اختياري بلا اسم افتراضي.
- تحليل محلي لعادات الإنفاق واقتراحات توفير، ومساعد تجريبي يجيب باللهجة العراقية من بيانات الجهاز.
- تخزين البيانات في localStorage. البيانات تبقى على المتصفح والجهاز الحالي.

## فصل البيانات والخدمات

منطق الحسابات والتخزين مجتمع في `app.js`. الكائن `store` نقطة استبدال التخزين المحلي بمستودع API، ودالة `answer` نقطة ربط المساعد بخدمة خلفية. لا توضع مفاتيح AI في المتصفح؛ يتصل العميل بخادم التطبيق كي يحتفظ الخادم بالمفاتيح ويطبق المصادقة والتحقق.

بيانات المبالغ التجريبية كلها دينار عراقي. العملات الأخرى متاحة عند إضافة معاملة، لكن التحويل بين العملات غير مفعل في النسخة الأولية.
